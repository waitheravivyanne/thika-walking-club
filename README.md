# Thika Walking Club (TWC)

A modern website for Thika Walking Club.

## About
Thika Walking Club promotes fitness, wellness,
community engagement and healthy lifestyles.

## Features
- Club information
- Activities and events
- Event registration
- Photo and video gallery
- Merchandise shop
- Online payments
- Member accounts
- Administration dashboard

## Technologies
- React
- Vite
- CSS
- Python Flask
- PostgreSQL
